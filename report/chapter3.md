# Capítulo III: Requirements Specification

Este capítulo presenta la especificación de los requisitos de EasyPark a partir del análisis de la información obtenida en las investigaciones previas. Se detallan las User Stories y Technical Stories derivadas de los Epics identificados, el Impact Mapping que vincula los objetivos de negocio con los segmentos objetivo, y el Product Backlog priorizado para el desarrollo del producto.

## 3.1. User Stories

A continuación se presenta el conjunto de Epics y User Stories identificadas para EasyPark. Cada User Story incluye sus criterios de aceptación redactados en tiempo presente, tercera persona y bajo la estructura Gherkin (Given-When-Then). Se incluyen también las User Stories correspondientes al sitio web estático (Landing Page), redactadas con el rol *visitante* y sus variantes por segmento (*visitante conductor*, *visitante administrador*).
