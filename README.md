 # EasyPark - Documentación del Proyecto

 Repositorio de documentación del proyecto **EasyPark**, desarrollado por un equipo de estudiantes de **Ingeniería de Software de la Universidad Peruana de Ciencias Aplicadas (UPC)**.

 ## Resumen

 EasyPark propone una plataforma digital para mejorar la gestión de estacionamientos y la experiencia de los conductores, enfocándose en:

 - Consulta y gestión de disponibilidad de espacios.
 - Registro digital de ingresos y salidas.
 - Reserva anticipada de estacionamientos.
 - Supervisión y reportes para administradores.
 - Reducción del tiempo y la incertidumbre al buscar estacionamiento.

 Este repositorio incluye la documentación del proyecto, abarcando la investigación del problema, análisis de usuarios y competidores, entrevistas, requerimientos, diseño, arquitectura, implementación y evidencias del desarrollo.
